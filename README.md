# ✨ Steam OAuth for Flarum
Adds a Steam OpenID 2.0 provider for [FoF OAuth](https://github.com/FriendsOfFlarum/oauth). Supports **Flarum 2.x**


## 🚀 Features
- ⚙️ Steam login via FoF OAuth
- 🎨 Styled login button for the forum frontend


## 📦 Installation
Run this in your Flarum root directory:

```
composer require forumaker/steam-oauth:"*"
```


## 📸 Screenshots


## 🛠️ Configuration
1. Get your Web API key at `https://steamcommunity.com/dev/apikey`
2. Enter your Steam Web API Key in the FoF OAuth provider settings
